# 銀行マスタ・支店データの運用手順

## データの出どころ
- 支店の一覧は、npm パッケージ `zengin-code`（有志のオープンソース。元データは個人運営の銀行検索サイト）を同梱しています。
- **公式（全銀協・全銀ネット）のデータではありません。** 統廃合・名称変更の反映に遅れが出ることがあります。

## 手動管理と最新化（画面から・別管理）
- 銀行マスタ（管理者）の「**支店データを最新化**」ボタンで、任意のタイミングに、自動連携の支店データを最新にできる。
  公開元（GitHub: zengin-code/source-data）から、マスタに登録済みの銀行コードごとに取得し、DB（`bank_branch_cache`）に保存し直す。
  結果は「追加・名称変更・提供元から削除」の件数で表示される。取得に失敗した銀行は、既存のデータのまま残る。
- 各銀行の「支店の管理」で、手動で支店を追加できる（支店名・コード・読み・メモ）。
  手動の支店は別の表（`bank_branch_overrides`）に保存されるので、**最新化しても消えない**。
- 自動連携の支店は、廃止扱いにしない（最新化で復活してしまうため）。廃止された支店は、最新化で提供元から消えた時点で、選択肢から無くなる。
- 発注先・自社口座の支店の選択肢は、「自動連携 ＋ 手動追加」の合算で出る（手動追加は「手動」と表示）。

## 運用ルール
1. **振込先（銀行・支店・口座番号）は、取引先の請求書・通帳の記載と照らして、最終確認する。**
2. 画面の支店の一覧に無い支店（廃止・名称変更・新設の直後）は、手入力で登録できる。
   - 支店の選択欄を開き、上の欄に支店名を入力して「この入力のまま使う」を押す。
3. 一覧に無い支店が保存されている場合、支店欄に「現行の支店一覧にありません」と注意が出る。
   通帳・請求書の記載どおりなら、そのままでよい。記載と違えば選び直す。
4. 銀行（金融機関）が一覧に無い場合は、銀行マスタ（管理者）に、銀行名と4桁の銀行コードを登録する。

## データの更新手順（手動・必要なとき）
```bash
bun update zengin-code
NODE_ENV=development bun run scripts/verify-banks.ts
```
- `verify-banks.ts` は、銀行マスタのコードの突合と、発注先・自社口座に登録済みの支店が、現行の一覧に残っているかを表示する。
- 「存在しない支店」と出たものは、取引先の記載を確認して、選び直すか、そのまま（手入力）とする。
- 更新後は、型チェックとテストを実行してから、デプロイする。
