# ADR-0021: 5年を過ぎた案件の書類を、画像を再圧縮したZIPで保管する（月次バッチ）

## メタ情報

- **ステータス**: 提案中(Proposed)
- **日付**: 2026-10-28
- **決定者**: Claude Code（承認: 人間レビュアー）

## コンテキスト（背景と課題）

アップロードした書類（契約書・見積書・請書・請求書・報告書）は、DBに文字列（base64）やバイナリで保存している。1ファイルは3MBまで。スキャンしたPDFが中心になると、年に1〜2GB近く増え、Supabaseの無料枠（500MB）を超える。古い案件の書類は、画面から見られなくなっても構わないため、画質を落として小さくし、まとめて保管する。

## 決定内容

- **対象**: 引渡月から5年（`ARCHIVE_AFTER_YEARS`）を過ぎた案件の、すべての書類（契約書、見積書、報告書などの書類、請書・請求書、発行した請求書PDF）。引渡月が空の案件は対象にしない
- **実行**: 毎月15日の23:00（日本時間）。Vercel Cronの `/api/cron/archive-old-files`（`vercel.json`、UTC 14:00）。Hobbyのcronは時刻に最大1時間の幅がある。`?dry=1` で、何も書き換えず、減る量だけを確認できる
- **再圧縮**: PDF内のJPEG画像を、長辺1200px・品質40に落として入れ替える（`pdf-lib` と `sharp`。Vercelでは Ghostscript が使えない）。JPEG以外の画像、画像の無いPDF、小さくならないPDFは、そのまま入れる
- **保管**: 案件ごとに1つのZIP（`file_archives.zip`、DB内）にまとめる。ZIPの中は、種類別のフォルダに分ける。ファイルごとの元の保存先と、圧縮前後のサイズは `manifest` に残す
- **元の書類**: ZIPを保存して読み戻せることを確認してから、元の本体（`data_url` / `pdf`）だけを空にする（同じトランザクション）。行・ファイル名は残すので、「請書が無い」などの通知は、変わらない。`project_documents` は `data_url` が必須のため、空文字にする
- **画面**: アーカイブ済みの書類は、開けなくなる（404）。ZIPは、管理者だけが `/api/archives/{id}` からダウンロードできる。発行した請求書は、保存したPDFが無い場合の再生成の経路があるため、画面では開ける
- **時間切れ**: 1回の実行は45秒で打ち切り、残りは翌月に持ち越す（`remainingProjects`）

## 影響

### ポジティブ

- 古いスキャンPDFの容量が、大きく減る。画面の動作や、一覧の取得は、変わらない

### ネガティブ

- アーカイブ後は、画面で書類を見られない。画質は戻せない（元の本体は消える）
- 税務上の保存期間（原則7年）より短い。画質を下げた書類でも、読める必要がある。保存期間は、税理士に確認すること
- ZIPもDBに置くため、容量の削減は、画像の再圧縮による分に限られる。さらに減らすには、オブジェクトストレージへの移行が必要
