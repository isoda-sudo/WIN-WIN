# ADR-0020: 銀行の支店データ（自動連携と手動追加の分離、最新化ボタン）

## メタ情報

- **ステータス**: 提案中(Proposed)
- **日付**: 2026-10-27
- **決定者**: Claude Code（承認: 人間レビュアー）

## コンテキスト（背景と課題）

発注先・自社口座・定期支払いの支店は、銀行マスタの銀行コードから、支店を選べるようにした。支店データは、有志が公開しているオープンソース（`zengin-code`、元データは全銀協のものではない個人運営のサイト）を使っている。全銀協・全銀ネットには、支店データのAPIがない。支店の統廃合・新設に追従する手段と、データを最新にしても手動で補った支店が消えないことが必要だった。

## 決定内容

- **データの二層**: 自動連携のデータと、手動で追加した支店を、別のテーブルで管理する。
  - 自動連携: 同梱の `zengin-code`。最新化すると、銀行ごとの取得結果を `bank_branch_cache` に保存し、以後はそれを使う
  - 手動追加: `bank_branch_overrides`（銀行ごと。支店名・コード・読み・メモ）
  - 選択肢は、「自動連携 ＋ 手動追加」の合算。手動追加には「手動」と表示する
- **廃止扱いは設けない**: 自動連携の支店を非表示にする機能は、最新化で復活するため、採らない。廃止された支店は、最新化で提供元から消えた時点で、選択肢から無くなる
- **最新化ボタン**: 銀行マスタ（管理者）の「支店データを最新化」。マスタに登録済みの銀行コードごとに、公開元（GitHub の `zengin-code/source-data`）から最新を取得し、`bank_branch_cache` に保存し直す。結果は、追加・名称変更・提供元から削除の件数で表示する。取得に失敗した銀行は、既存のデータのまま
- **手動の追加**: 銀行マスタの「支店の管理」（管理者）で、銀行ごとに手動の支店を追加・削除する。最新化しても消えない
- **現行の一覧に無い支店**: すでに保存された支店が一覧に無い場合は、注意を出し、そのまま使うこともできる
- **定期支払い**: 支払先を銀行マスタから選べる入力にし、銀行を選ぶと、その銀行の支店を選べる。銀行以外（年金機構・電力会社など）は、そのまま入力できる

## 影響

### ポジティブ

- 統廃合に、任意のタイミングで追従できる。手動の補いが、最新化で消えない

### ネガティブ

- 公開元は、有志のデータで、正式な（公的な）ものではない。反映の遅れがありうる
- 振込先は、取引先の請求書・通帳と照らして、最終確認する運用が必要
