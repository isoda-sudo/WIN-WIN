# 操作動画の作り方（録画の仕組み）

1本の動画は、`台本のスクリプト（.mjs）` を実行して作る。台本は、画面の操作と、ナレーションの文を、組にして書く。

## 流れ（1本あたり約2分半〜6分）
1. 録画用の複製DB（`demo` スキーマ）を、元に戻す。本番（`public`）には触れない。
2. 確認だけの実行（`DEMO_DRY=1`）。画面は録画せず、すべての操作と確認項目を、先に動かす。不合格が1件でもあれば、録画しない。この間に、ナレーションの音声も、先に作る（キャッシュ）。
3. 複製DBを戻して、本番の録画。ナレーションの音声に合わせて、操作を進める。
4. 音声を、実測の開始時刻に合わせて重ね、字幕を焼き込んで、mp4にする。

## 軽快さの工夫
- 操作の間の待ちは、台本の値の約35%に圧縮する（`DEMO_PACE`）。
- ナレーションは、約8文字/秒（`DEMO_SPEED`、既定1.3倍）。句読点の間も、詰める。
- 場面の切れ目に、待ちを入れない。ナレーションの終わりと、次の場面の始まりが、すぐにつながる。
- 録画は、新しいheadless Chromiumで、PDFのプレビューも、実際の表示になる。

## 使い方
```bash
bash scripts/demo/start-demo.sh                 # 録画用のアプリ（demoスキーマ、ローカルSMTP）を起動
bash scripts/demo/make.sh v06-payment.mjs      # 1本作る（確認 → 録画 → 書き出し）
bash scripts/demo/make-all.sh v01-login.mjs v02-mfa.mjs ...   # 続けて作る
```
- 動画（.mp4）は、容量が大きいため、Gitには入れない（`.gitignore`）。字幕（.srt）と確認レポートは、入れる。
- 台本とスクリプトは `scripts/demo/` にある。`reset-demo.sh` は、録画用の複製DB（`/tmp/demo-schema2.sql`、`/tmp/demo-data2.sql`）を前提にする。

詳細な確認結果は `CHECK-REPORT.md`。
